# Mwenaro Figma Design Responsiveness

A simple responsive landing page built with HTML and CSS.

## Project Overview

This project is a static front-end page inspired by a Figma design. It includes:

- A hero section with a heading, paragraph, button, and responsive hero images
- A stats/list section showcasing metrics
- An additional image showcase section with responsive cards
- Desktop-specific layout adjustments for better spacing and overlay

## Files

- `index.html` - the main HTML page
- `style.css` - the stylesheet for layout and responsive behavior
- `assets/` - folder containing image assets used by the page

## How to Open

1. Open `index.html` in a browser.
2. Use the browser developer tools to inspect responsive styles.

## Key Features

- Responsive typography and spacing
- Hero image overlap layout for desktop
- Centered list/stats section
- Image showcase grid with consistent card sizes
- Desktop-only overlay effect from the stats section onto the image showcase

## Notes

- Images are referenced from the `assets/` folder using relative paths.
- The current design is fully static and does not require a web server, but using one can help with browser file permissions.
- Update `style.css` for layout changes, responsive breakpoints, and color/theme adjustments.

## Suggestions for Improvements

- Add navigation and footer sections
- Improve accessibility with more semantic HTML and ARIA labels
- Add hover effects to buttons and image cards
- Convert the layout to use CSS Grid or Flexbox consistently for more advanced responsive control
